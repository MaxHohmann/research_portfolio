## Selected projects

### 1. Rapid Serial Motion Detection

**MWorks · Psychophysics · Eye Tracking · Motion Perception**

A psychophysical paradigm for investigating the detection of brief
changes in motion direction within a rapid sequence of random-dot
motion stimuli.

The experimental implementation integrates:

- Random-dot motion stimuli
- Dual-task target detection
- Controlled temporal target allocation
- Online fixation monitoring
- Eye tracking
- Drift correction
- Trial-level behavioral logging

**Key methodological focus:** precise experimental timing and controlled
presentation of behavioral targets.

[View project →](./RapidSerialMotionDetection-main/)

---

### 2. Hierarchical Frequency Tagging

**EEG · Frequency Tagging · Signal Processing**

A frequency-tagging framework for investigating hierarchical and
frequency-specific neural responses to visual stimulation.

The project explores the use of frequency-specific neural signatures
to characterize the flow of visual information across processing
levels.

**Methods include:**

- Frequency-domain analysis
- SSVEP analysis
- Spectral decomposition
- Stimulus-response characterization
- Neural signal analysis

[View project →](./Hierarchical_Frequency_Tagging/)

---

### 3. NeuroSpecMMBTS

**EEG · Neural Signal Analysis · Computational Methods**

A computational framework for analyzing neural signals in the context
of frequency-specific visual processing.

The project provides examples of quantitative approaches for extracting
and characterizing temporal and spectral structure in neural data.

[View project →](./NeurospecMMBTS-main/)
